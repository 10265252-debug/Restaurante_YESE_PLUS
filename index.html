NUESTRA HISTORIA

Más que comida, creamos recuerdos.

Restaurante YESE nace con una idea sencilla: reunir a las personas alrededor de platos deliciosos, atención amable y un ambiente donde todos se sientan bienvenidos.

Nuestra misión es ofrecer una experiencia agradable con alimentos preparados con dedicación. Nuestra visión es ser un lugar favorito para celebrar, compartir y volver.

La tecnología detrás de YESE

Este sitio combina herramientas web para presentar el restaurante de forma clara, adaptable y fácil de navegar.

HTML5

Organiza el contenido: títulos, secciones, imágenes y formularios.

CSS3

Define colores, tipografías, espacios y diseño adaptable.

Bootstrap Icons

Aporta iconos visuales para mejorar la navegación.

JavaScript

Permite filtrar el menú, cambiar idioma y activar el tema oscuro.

Diseño responsive

Se adapta a computadora, tableta y teléfono.

JSON

Formato común para organizar datos, por ejemplo productos y precios.

Dominio
