# Restaurante YESE PLUS

## Cómo abrirlo
1. Extraé `Restaurante_YESE_PLUS.zip`.
2. Abrí la carpeta y hacé doble clic en `index.html`.
3. Necesitás internet para cargar las fotografías, la tipografía y los iconos externos.

## Incluye
- Diseño adaptable para computadora y celular.
- Menú ampliado con 12 opciones y filtros por categoría.
- Selector español/inglés.
- Modo claro/oscuro.
- Secciones: inicio, quiénes somos, menú, servicios, galería, portafolio técnico, cuestionario y contacto.
- Cuestionario interactivo de 5 preguntas.
- Formulario de contacto de demostración que prepara un correo; no guarda ni envía datos a un servidor.

## Personalización
- Cambiá textos, precios, horarios y dirección de ejemplo dentro de `index.html`.
- Para cambiar una foto, buscá la etiqueta `<img src="...">` correspondiente y sustituí su URL por la de tu imagen.
- Los precios y datos son ejemplos para el proyecto escolar. Confirmá los datos reales antes de publicar.

## Publicación
Podés subir esta carpeta a GitHub y conectarla a Vercel o usar GitHub Pages. No incluye un dominio ni está publicado automáticamente.
